# حزمة البدء لمنصة رفد — ابدأ من هنا

كل ما تحتاجه لبناء منصة رفد (منصة مسارات تعليمية لطلاب اليمن، أولها مسار الإنجليزي حتى الشهادة الدولية) باستخدام Claude Code، **دون أن تكتب سطر كود واحد**.

## محتويات الحزمة

| الملف | ما هو | لمن |
| --- | --- | --- |
| `docs/GUIDE_AR.md` | الدليل خطوة بخطوة: الحسابات وطريقة العمل والمحتوى والإطلاق | **أنت — ابدأ به** |
| `docs/BUILD_PROMPTS.md` | برومت جاهز لكل مرحلة بناء (0 إلى 8) | أنت تنسخ، و Claude ينفذ |
| `docs/CONTENT_PROMPTS.md` | برومتات خريطة المنهج وبناء الوحدات وتحسينها | أنت تنسخ، و Claude ينفذ |
| `docs/PRD.md` | وثيقة المتطلبات الكاملة (v3) | Claude، وأنت للرجوع |
| `docs/SCREENS.md` | كل شاشة: الرابط، ملف التصميم، المحتوى، الحالات | Claude |
| `docs/OFFLINE.md` | طريقة عمل المنصة بلا إنترنت وبباقة ضعيفة | Claude |
| `docs/AI_PROMPTS.md` | تعليمات الذكاء الاصطناعي لتقييم المحادثة والكتابة والمساعد | Claude |
| `docs/HANDOFF.md` | ملخص كل قرارات المحادثة السابقة وروابط المخرجات، ليعرف Claude Code القصة كاملة | Claude |
| `CLAUDE.md` | قواعد المشروع، يقرؤها Claude Code تلقائياً كل جلسة | Claude |
| `design/` | تصميم كل الشاشات (ديسكتوب وموبايل) والشعارات | Claude، وأنت من لوحة التصميم |
| `content/` | شكل ملف الوحدة، ومثال وحدة، ومكان الوحدات | Claude |

## الطريق باختصار

1. اقرأ `docs/GUIDE_AR.md` وأنشئ الحسابات الأربعة (ساعة تقريباً).
2. ارفع محتويات هذه الحزمة إلى مستودع GitHub جديد.
3. افتح Claude Code على الويب، واختر المستودع، والصق برومت **المرحلة 0**.
4. جرّب على هاتفك من رابط المعاينة، ثم ادمج. وكرر مع كل مرحلة.
5. من الأسبوع الثالث ابنِ المحتوى بالتوازي.

**التكلفة: صفر** ما عدا اشتراك Claude. **قبل استقبال طلاب حقيقيين:** مراجعة أمنية من مطور متطوع (المرحلة 6).
