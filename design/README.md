# التصميم

كل ملف `.dc.html` شاشة واحدة: المنتهي بـ `M` للموبايل (390px)، والباقي للديسكتوب (1440px). خريطة الشاشات والروابط في `docs/SCREENS.md`.

- `Main.dc.html`: الهوية ونظام التصميم (الألوان، الخطوط، المكونات).
- `later/`: شاشات مؤجلة (المجتمع، وكيل بناء المسارات، المشاريع). للرجوع فقط، لا تُبنى الآن.

هذه الملفات مصدر التصميم ليقرأه Claude Code (التخطيط والمسافات والنصوص والألوان)، وقد لا تُعرض كاملة إذا فتحتها مباشرة في المتصفح. لمشاهدة التصميم والتعليق عليه افتح لوحة التصميم على Claude.
